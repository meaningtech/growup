# Code of conduct

GrowUp is built around careful evidence, transparent decisions and respect for the people and places affected by technology. The same standard applies to this community.

## Expected behavior

- Be respectful, specific and constructive.
- Welcome different levels of experience and domain knowledge.
- Critique ideas and implementations, not people.
- Cite sources and state uncertainty when making technical or scientific claims.
- Protect private, sensitive and identifiable project data.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, deliberate misinformation and the publication of private data or credentials are not tolerated in project spaces.

## Reporting and enforcement

Report conduct concerns privately to `hello@meaningtech.io`. Maintainers may edit or remove contributions, restrict participation or take other proportionate action to protect the community. Reports will be handled as confidentially as reasonably possible.

This code applies to repository activity, project discussions and other spaces where someone represents GrowUp or meaningtech.
